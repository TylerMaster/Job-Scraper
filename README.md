# Job Scraper Platform

A platform that collects, organizes, and analyzes software engineering job postings.

## Goals

- Scrape job postings from public sources
- Store job data in a PostgreSQL database
- Provide an API for searching and filtering jobs
- Build a frontend interface for users

## Planned Technologies

- Python (web scraping)
- Spring Boot (backend API)
- PostgreSQL (database)
- React (frontend)
- Docker (deployment)

## Status

Project in development.
